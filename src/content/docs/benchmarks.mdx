## Условия

- **Remnawave 3.4.5** (`remnawave/backend:3.4.5`) против **GoWave** с оптимизациями пула PostgreSQL, фоновой записи истории подписок и статистики дашборда.
- Docker, у каждой панели лимит **2 CPU и 2 ГиБ**, свой **PostgreSQL 17 с 1 CPU** и одинаковыми настройками. У Remnawave дополнительно Valkey (0,5 CPU), без которого она не работает.
- Одинаковые данные, созданные через API каждой панели: 1000 пользователей, 20 хостов, профиль и сквад.
- Нагрузку даёт [k6](https://k6.io) 1.6.1: каждая итерация - один HTTP-запрос. Ответы проверяются: ошибка, пустая подписка или HTML считаются неуспешными.
- Порядок прогонов чередуется и перемешивается; перед каждым - прогрев. Каждый прогон длится 20 секунд, повторов два, в таблицах - медиана.
- Задержка - время ответа сервера (`timings.duration` в k6), p99 - медиана по прогонам.

## Пропускная способность

Режим *concurrency*: заданное число клиентов отправляет запросы без пауз, следующий - сразу после ответа. Так видно, сколько запросов в секунду панель реально выдерживает.

## Память и запуск

- **Память** (медиана по всем прогонам, контейнер панели целиком, включая воркеры): GoWave - около 51 МиБ, Remnawave - около 1030 МиБ.
- **Запуск** до первого ответа API с авторизацией (медиана 10 попыток): GoWave - 228 мс, Remnawave - 4,8 с.

## Что важно знать

- **Статистика от 32 клиентов (до 13×)** - заслуга объединения одновременных запросов: пока одно вычисление идёт в базе, остальные ждут его результат. Такое «стадо» запросов к одному эндпоинту бывает редко; повседневную разницу лучше показывает один клиент - **2,9×**.
- **Запись при одном клиенте GoWave медленнее** (156 против 240 запросов/с). С ростом нагрузки GoWave обгоняет: при 8-128 клиентах - в 1,3-1,7 раза. Причину ищем.
- **Ноды в тесте не участвуют.** Не измерялись работа с нодами, сбор трафика, HWID и реальные VPN-клиенты - только API панели.
- **Это проверка на одной машине**, а не замер предельной мощности: прогоны короткие, оборудование - рабочая станция. Цифры показывают соотношение, а не абсолютные пределы.
