Панель слушает только `127.0.0.1:3000` и наружу отдаётся через reverse proxy с HTTPS. Установщик настраивает его сам, а для ручной установки подойдёт один из двух вариантов:

- [Caddy](../caddy/): проще всего, сертификат выпускается и продлевается сам.
- [Nginx](../nginx/): если Nginx уже стоит на сервере. Сертификат выпускается через Certbot.

:::tip[WebSocket]
Заголовки `Upgrade` и `Connection` нужны для SSH-терминала нод в панели.
:::
