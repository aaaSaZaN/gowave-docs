[Установщик](../../install/installer/#переезд-с-другой-панели) сам находит Remnawave и PasarGuard и предлагает перенос. Команды ниже - для ручного запуска. Исходные базы во всех сценариях только читаются.

Обе команды находят базу Remnawave по `/opt/remnawave/.env` и подключаются к ней через опубликованный порт `127.0.0.1:6767`. Другой адрес передайте DSN первым аргументом. Пока идёт копирование, лучше остановить контейнер `remnawave`, а базу `remnawave-db` оставить работать: так в неё ничего не запишется посередине переноса.

## В SQLite

```bash
gowave migrate pg-to-sqlite
```

- Переносятся все таблицы: пользователи, трафик, ноды, хосты, шаблоны, сквады.
- Исходная база и `.env` не меняются. По умолчанию создаётся `gowave-migrated.sqlite`: укажите его в `DATABASE_URL` с `DB_DRIVER=sqlite` и перезапустите GoWave. Установщик делает это сам.
- Интерактивное меню (`gowave rescue`, пункт 8) после переноса предложит остановить и удалить контейнеры `remnawave`, `remnawave-db`, `remnawave-redis` - только после подтверждения.

## В PostgreSQL

Если GoWave уже работает на PostgreSQL, например в [Docker](../../install/docker/), данные копируются из базы в базу без промежуточного SQLite:

```bash
gowave migrate pg-to-pg
```

Или с явными адресами:

```bash
gowave migrate pg-to-pg \
  'postgresql://postgres:ПАРОЛЬ@127.0.0.1:6767/postgres' \
  'postgresql://gowave:ПАРОЛЬ@127.0.0.1:5432/gowave?sslmode=disable'
```

Второй адрес - PostgreSQL GoWave. В Docker-установке он опубликован на `127.0.0.1:5432`, пароль лежит в `POSTGRES_PASSWORD` в `/opt/gowave-docker/.env`. Запускайте команду на хосте, где видны обе базы. Изнутри контейнера панели порт Remnawave на loopback хоста недоступен.

Как работает перенос:

- Источник читается в одной транзакции только для чтения, поэтому данные согласованы на момент начала.
- Цель пишется одной транзакцией: если что-то пошло не так, база GoWave остаётся как была.
- Если в целевой базе уже есть пользователи, ноды или хосты, команда остановится. `--force` разрешает их заменить.
- Команда откажется копировать базу саму в себя и не примет в качестве источника базу GoWave.
- В конце она выводит отчёт: какие таблицы и столбцы Remnawave GoWave не хранит и какие таблицы GoWave остались пустыми.

После переноса проверьте, что в `.env` панели стоят `DB_DRIVER=postgres` и `DATABASE_URL` целевой базы (в Docker это уже так), перезапустите панель и войдите под прежним администратором. Старую панель останавливайте, когда убедитесь, что всё на месте.

Установщик при выборе «PostgreSQL в Docker» делает то же самое через [`gowave migrate to-docker --from-upstream`](../sqlite-to-docker/#флаги): создаёт проект Docker и копирует Remnawave прямо в его PostgreSQL.
