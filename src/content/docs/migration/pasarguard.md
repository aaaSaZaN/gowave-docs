[Установщик](../../install/installer/#переезд-с-другой-панели) сам находит PasarGuard и предлагает перенос. Команды ниже - для ручного запуска. Исходные базы во всех сценариях только читаются.

Перед импортом остановите запись в PasarGuard и сделайте копию базы GoWave. Если сомневаетесь, сначала импортируйте в отдельную тестовую базу. Запускайте команду из каталога панели, чтобы она взяла `.env` GoWave.

```bash
# Найти базу автоматически
gowave import pasarguard

# Файл SQLite
gowave import pasarguard /opt/pasarguard/data/db.sqlite3

# Резервная копия PasarGuard
gowave import pasarguard /root/pasarguard-backup.zip

# PostgreSQL или TimescaleDB
gowave import pasarguard 'postgresql://user:password@localhost/pasarguard'
```

Без аргумента база находится по `SQLALCHEMY_DATABASE_URL` из `/opt/pasarguard/.env` (SQLite, PostgreSQL или TimescaleDB, в том числе через pgbouncer) или по файлу `/var/lib/pasarguard/db.sqlite3`. MySQL и MariaDB не поддерживаются. В ZIP-архиве `db.sqlite3` должен лежать в корне, вложенные старые копии не читаются. Пароль из DSN в журнал не выводится.

Импорт пишет в GoWave одной транзакцией: при ошибке не меняется ничего. В меню `gowave rescue` это пункт 7.

## Что переносится

- Пользователи: VLESS UUID, пароли Trojan, Shadowsocks и Hysteria, лимиты трафика и стратегии сброса, сроки, заметки, отзыв подписки, текущий и накопленный трафик, время последнего подключения.
- HWID-устройства и время их последнего использования.
- Профили Xray (`core_configs`) и их inbound'ы.
- Группы - как внутренние сквады, вместе со связями пользователей и inbound'ов. Если групп в базе нет, пользователи попадают в первый сквад GoWave.
- Основные параметры хостов.
- Ноды, история трафика нод и пользователей, история запросов подписки.

Числовые ID назначаются заново, связи между записями сохраняются.

## Повторный импорт

Его можно запускать снова, например перед окончательным переездом. Пользователи обновляются по имени, остальные записи - по постоянным идентификаторам, которые импорт выводит из ID PasarGuard. Данные заменяются актуальным состоянием источника. Не переименовывайте импортированные записи между запусками, иначе повтор создаст дубликаты.

## Что придётся сделать руками

- **Ноды** импортируются отключёнными: сертификаты и API-ключи PasarGuard для GoWave не подходят. Поставьте на серверы [GoWave Node](../../install/node/install/) и включите ноды в панели.
- **Пользователи `on_hold`** становятся отключёнными. Отложенную активацию придётся настроить заново.
- **Ссылки подписки** меняются: GoWave создаёт собственные идентификаторы, старые ссылки PasarGuard не работают. Раздайте пользователям новые.
- Не переносятся администраторы, роли и права, JWT, API-ключи, уведомления, настройки панели, шаблоны подписок другого движка, планы продления и параметры хостов, у которых нет аналога в GoWave.
