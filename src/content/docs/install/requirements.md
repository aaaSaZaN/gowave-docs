:::tip[Если совсем коротко]
- **Процессор:** любой, на котором запускается Linux. Большую часть времени панель просто ждёт запросов.
- **Память:** около 50 МБ. Одна вкладка браузера с этой страницей занимает больше.
- **Диск:** бинарник на 28 МБ, веб-интерфейс и файл базы. Поместится там, где не поместится Docker.
- **Терпение:** 0,2 секунды на запуск. Моргнуть вы, может быть, и успеете.
:::

## Сервер

- Linux на `amd64` или `arm64`. Установщик поддерживает Debian, Ubuntu и дистрибутивы семейства RHEL.
- Доступ root.
- Открытые порты 80 и 443 для HTTPS. Сама панель слушает только `127.0.0.1:3000`.

## Домен

Нужен домен или поддомен, A-запись которого указывает на IP сервера. Панель отдаётся только по HTTPS, сертификат выпускается на этот домен. Для [страницы подписки](../subscription-page/) обычно заводят ещё один поддомен.

## Память

Панель работает одним процессом и под нагрузкой занимает около 50 МБ, см. [бенчмарки](../../benchmarks/).

| Вариант | Что работает на сервере |
| :--- | :--- |
| [Systemd и SQLite](../systemd/) | Только панель, база хранится в файле рядом с ней |
| [Docker и PostgreSQL](../docker/) | Панель и PostgreSQL в контейнерах. Под нагрузкой бенчмарка PostgreSQL занимал около 140 МБ |

Ноды ставятся на отдельные серверы, требования к ним описаны на странице [установки Go-ноды](../node/install/).
