## Почему GoWave

<CardGrid>
	<Card title="Лёгкий" icon="rocket">
		Один процесс на Go: около 60 МиБ памяти под нагрузкой, у Remnawave около 1 ГиБ. Панель готова отвечать через 0,2 секунды после старта.
	</Card>
	<Card title="Совместимый" icon="approve-check">
		API по контракту `@remnawave/backend-contract`, веб-интерфейс Remnawave, ноды `remnawave/node` и Go-нода, страница подписки.
	</Card>
	<Card title="SQLite или PostgreSQL" icon="seti:db">
		Один файл SQLite без Docker или PostgreSQL в Docker. Переехать с одного на другое можно одной командой.
	</Card>
	<Card title="Установка одной командой" icon="laptop">
		Установщик сам настроит HTTPS через Caddy или Nginx и перенесёт данные с Remnawave или PasarGuard.
	</Card>
</CardGrid>

sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/aaaSaZaN/gowave/main/install.sh)"
