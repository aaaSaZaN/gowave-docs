Если нода работает в Docker на образе `remnawave/node`, её переводит на [GoWave Node](../../install/node/install/) тот же установщик (от root на сервере ноды):

```bash
sudo sh -c "$(curl -fsSL https://raw.githubusercontent.com/aaaSaZaN/gowave-node/main/install.sh)"
```

Установщик находит контейнер и переносит его окружение (`SECRET_KEY`, `NODE_PORT` и остальное) в `.env` Go-ноды, поэтому в панели ничего менять не нужно.

Что происходит по шагам:

1. Пока контейнер работает, установщик читает его текущую конфигурацию Xray и проверяет, что файлы сертификатов и ключей из неё (`certificateFile`, `keyFile`, `dhFile`) доступны на хосте. Если файл лежит только внутри контейнера, установщик остановится, а Docker не тронет. Скопируйте или смонтируйте такие файлы на хост и запустите команду снова.
2. Скачивает и проверяет релиз, ставит службу `gowave-node`.
3. Отключает у контейнера автозапуск, останавливает его и запускает Go-ноду.
4. Ждёт до двух минут, пока нода получит конфигурацию от панели и запустит Xray. Если не дождался, возвращает контейнер с прежней политикой перезапуска.

Сам контейнер не удаляется: он остаётся остановленным на случай ручного отката. Когда Go-нода проработает какое-то время без проблем, удалите его сами.

Если на сервере одновременно найдены и Docker-нода, и старая нативная служба `remnanode`, установщик не будет гадать и попросит сначала оставить одну из них.
