Нужны сервер на Debian/Ubuntu или RHEL-семействе (`amd64` или `arm64`) и домен, A-запись которого указывает на IP сервера. Панель открывается только по домену через HTTPS, поэтому без домена установщик не продолжит. Если прокси свой, домен может указывать и не на этот сервер.

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/aaaSaZaN/gowave/main/install.sh)"
```

## Что спросит установщик

1. **База данных.** SQLite - один файл, без Docker, обновление прямо из панели. Или PostgreSQL в Docker.
2. **Reverse proxy.** Caddy (сертификат выпускается и продлевается сам), Nginx с Certbot или свой прокси, см. [ниже](#свой-reverse-proxy).
3. **Домен панели.** Для Caddy и Nginx установщик проверит, что домен указывает на этот сервер.

## Что он сделает сам

- скачает релиз и сверит контрольные суммы `SHA256SUMS`;
- сгенерирует `APP_SECRET`;
- создаст службу `gowave`;
- настроит reverse proxy с HTTPS и откроет порты 80 и 443 в `ufw` или `firewalld`, если выбран Caddy или Nginx.

Панель слушает только `127.0.0.1` и доступна по `https://<домен>`.

:::caution[Сразу откройте панель]
Первый, кто откроет панель, создаёт администратора. Зайдите в неё сразу после установки.
:::

## Свой reverse proxy

Пункт «Не настраивать: свой reverse proxy» нужен, если на сервере уже работает свой прокси (Angie, Traefik, HAProxy, Caddy или Nginx в Docker), прокси стоит на другом сервере или панель открывается через Cloudflare Tunnel. Установщик поставит только панель и не тронет порты 80 и 443, прокси и файрвол. Проверки DNS тоже не будет.

В конце он покажет адрес, на который нужно направить прокси, обычно `http://127.0.0.1:3000`. Прокси должен передавать заголовки `Host`, `X-Forwarded-For` и `X-Forwarded-Proto`, а для SSH-терминала нод ещё WebSocket (`Upgrade` и `Connection`). Готовые настройки есть для [Caddy](../reverse-proxy/caddy/) и [Nginx](../reverse-proxy/nginx/).

:::note[Прокси в Docker]
Панель слушает только `127.0.0.1` сервера, и контейнер с прокси в обычной сети Docker её не увидит. Запустите прокси с `network_mode: host`.
:::

Пока прокси не настроен, панель открывается только с самого сервера, поэтому создать администратора извне никто не сможет. Перейти на Caddy или Nginx позже можно через пункт меню «Настроить домен и HTTPS».

## Переезд с другой панели

Если на сервере найдена **Remnawave** (`/opt/remnawave`) или **PasarGuard** (`/opt/pasarguard`, SQLite или PostgreSQL/TimescaleDB), установщик предложит перенести данные в GoWave - на SQLite или на PostgreSQL в Docker.

Старая панель останавливается и пропадает из автозагрузки, но её контейнеры и данные остаются на месте. Если перенос не удался, установщик включит её обратно. Подробнее - в разделе [Миграция](../../migration/remnawave/).

## Повторный запуск

Та же команда на сервере, где GoWave уже стоит, открывает меню: обновить, сменить домен и прокси, удалить (по желанию - с резервной копией базы).

Конкретную версию можно поставить так:

```bash
sudo GOWAVE_VERSION=v1.2.3 bash -c "$(curl -fsSL https://raw.githubusercontent.com/aaaSaZaN/gowave/main/install.sh)"
```

Лог установки: `/var/log/gowave-install.log`.
