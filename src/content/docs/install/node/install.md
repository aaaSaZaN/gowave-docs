GoWave Node ([gowave-node](https://github.com/aaaSaZaN/gowave-node)) управляет ядром Xray на сервере, через который идёт трафик пользователей. Это быстрая и легковесная реализация ноды на Go: она полностью совместима с протоколом Remnawave Node 3.4.2 и подключается как к GoWave, так и к оригинальной панели Remnawave. Xray работает отдельным процессом, Node.js и Docker не требуются.

Раньше проект назывался remnanode-go, а команда - `remnanode`. Старые установки установщик переводит на новое имя автоматически.

## Требования

- Linux. Архитектуры: `amd64`, `386`, `arm64`, `armv7`, `armv6`, `armv5`, `riscv64`, `mips`, `mipsle`, `mips64`, `mips64le`. Серверные проверки проходят на `amd64` и `arm64`, остальные сборки для роутеров не сертифицированы.
- Система запуска: systemd, OpenRC (Alpine), procd (OpenWrt) или Entware (Keenetic и другие opkg-системы).
- `curl` или `wget` и любой из `sha256sum`, `shasum`, `openssl`.
- Доступ root.
- Для фильтров трафика в плагинах нужны `nft`, `ss` (iproute2) и право `CAP_NET_ADMIN`.

## Установка из панели

При добавлении ноды панель показывает готовую команду: в ней уже подставлены `SECRET_KEY` и порт ноды. Скопируйте её кнопкой и выполните на сервере ноды.

Если панель стоит на этом же сервере, ноду можно поставить и [установщиком GoWave](../../installer/#локальная-нода).

## Быстрая установка скриптом

1. В панели добавьте ноду и скопируйте её `SECRET_KEY` из настроек ноды.
2. На сервере ноды выполните:

   ```bash
   sudo sh -c "$(curl -fsSL https://raw.githubusercontent.com/aaaSaZaN/gowave-node/main/install.sh)"
   ```

   Без `curl` подойдёт `sudo sh -c "$(wget -qO- https://raw.githubusercontent.com/aaaSaZaN/gowave-node/main/install.sh)"`.

3. Установщик спросит `SECRET_KEY` и `NODE_PORT` (по умолчанию `3000`). Порт должен совпадать с портом ноды в панели.

Установка без лишних вопросов (например, в автоматических скриптах):

```bash
sudo SECRET_KEY=... NODE_PORT=2222 sh -c "$(curl -fsSL https://raw.githubusercontent.com/aaaSaZaN/gowave-node/main/install.sh)"
```

Если указанный порт уже занят другой программой, установщик остановится до внесения изменений. Новая нода считается установленной, как только служба управления ответит (до 30 секунд), поэтому продолжать настройку в панели можно сразу. При обновлении или переезде установщик ждёт готовности Xray до 2 минут, а при неудаче возвращает прежнюю службу.

### Параметры установщика

| Переменная | Что задаёт |
| :--- | :--- |
| `SECRET_KEY` | Секретный ключ из настроек ноды в панели. Используется, только если нода ещё не настроена |
| `NODE_PORT` | Порт службы управления, по умолчанию `3000`. Порт должен совпадать с настройками ноды в панели |
| `GOWAVE_NODE_VERSION` | Тег конкретного релиза вместо последнего (например, `v1.1.5` или pre-release). Если тега нет, скрипт завершится без изменений |
| `GOWAVE_NODE_INIT` | Принудительный выбор системы инициализации: `systemd`, `openrc`, `procd` или `entware` |

Старые переменные с префиксом `REMNANODE_` также поддерживаются для обратной совместимости; переменные `GOWAVE_NODE_` имеют приоритет.

## Установка кастомных ядер Xray

По умолчанию `gowave-node` скачивает и использует стандартный бинарник Xray (`rw-core`). Однако вы можете установить любую версию или собственный форк Xray как через CLI, так и прямо из веб-панели GoWave.

### Через консоль ноды (CLI)

Команда `gowave-node core install` позволяет загрузить ядро из любого публичного GitHub-репозитория с указанием тега:

```bash
gowave-node core install --repo <владелец/репозиторий> --version <тег> -y
```

Примеры:

```bash
# Установка конкретной версии официального ядра XTLS/Xray-core
gowave-node core install --repo XTLS/Xray-core --version v26.7.28 -y

# Установка кастомного ядра или форка из стороннего репозитория
gowave-node core install --repo owner/custom-xray --version v1.0.0 -y
```

Требования к релизу стороннего репозитория:
- В GitHub Releases целевого репозитория должны быть прикреплены скомпилированные архивы (`.zip`) или исполняемые файлы под вашу архитектуру (например, `Xray-linux-64.zip` или архив под `arm64`).
- Нода автоматически распаковывает архив, проверяет совместимость пробным запуском конфигурации и только после успешной проверки активирует ядро.

### Через веб-панель GoWave

В карточке ноды в веб-интерфейсе GoWave:
1. Нажмите на текущую версию **Xray Core**.
2. В появившемся окне можно выбрать готовый релиз/pre-release или указать прямую HTTPS-ссылку на архив либо исполняемый файл ядра.

Пример прямой ссылки:
```text
https://github.com/XTLS/Xray-core/releases/download/v26.7.28/Xray-linux-64.zip
```
Или ссылка на raw-бинарник / сборку вашего форка:
```text
https://example.com/builds/xray-linux-64
```

Панель отправит команду ноде, нода скачает ядро по HTTPS, проверит его работоспособность и активирует его без прерывания связи.

### Сброс на стандартное ядро

Если требуется вернуться к стандартному поддерживаемому ядру `rw-core`:

```bash
gowave-node core reset
```

Команда удалит кастомные оверрайды, восстановит официальный бинарник `rw-core` и перезапустит процесс.

### Поведение при обновлении ноды

Команда `gowave-node update` обновляет исключительно бинарник самой ноды GoWave Node.

Установленное ядро Xray (включая кастомные форки, установленные через `--repo`, или ядра, загруженные по прямой ссылке) **не перезаписывается и не сбрасывается** при обновлении ноды.

## Подключение к панели

Нода не отправляет исходящих запросов к панели. Демон `gowave-node` слушает порт `NODE_PORT` (по умолчанию 3000), а панель сама подключается к нему по адресу `https://<ip-ноды>:<порт>`.

Соединение защищено взаимным TLS (mTLS на базе TLS 1.3) и токенами JWT RS256. Сертификаты и ключи запакованы в ключ `SECRET_KEY`, который создаётся при добавлении ноды в панели.

### Работа с Remnawave

Нода поддерживает протокол Remnawave Node версии 3.4.2:
- При проверке статуса и версии нода сообщает версию протокола `3.4.2`, чтобы оригинальная панель Remnawave проходила проверку совместимости.
- Синхронизация клиентов происходит поочерёдно: панель отправляет отдельный запрос на каждого пользователя (`add-user` и `remove-user`).

### Работа с GoWave

В связке с GoWave взаимодействие работает значительно быстрее и надёжнее:
- Панель передаёт заголовок `X-Better-One: true`. Нода отвечает своей реальной версией релиза и типом `go`. Панель отображает точную версию и даёт возможность обновлять ноду и ядро в один клик.
- Пакетная синхронизация: GoWave передаёт пользователей пачками до 1000 записей за один запрос через `add-users` и `remove-users`. При перезапуске или временном разрыве связи очередь не забивается тысячами мелких задач.
- Независимый опрос: проверка доступности выполняется каждые 15 секунд (до 32 одновременных проверок), а опрос статистики - каждые 5 секунд с равномерным распределением нагрузки во времени. Это защищает базу данных и сеть от пиковых всплесков. Если запись статистики сорвалась, данные повторяются в следующем цикле опроса без потерь.

## Что устанавливается

- Каталог установки: `/opt/gowave-node`.
- Служба systemd: `gowave-node.service` (работает от `root`, так как Xray требуется доступ к сокетам в `/dev/shm`, сертификатам сторонних служб и низким портам до 1024).
- Индекс ASN для плагинов: `/usr/local/share/asn/asn-prefixes.zip`.
- Симлинки в `/usr/local/bin`: `gowave-node` и `xlogs`.

## Entware (роутеры)

На Entware установщик создаёт скрипт `/opt/etc/init.d/S99gowave-node`. `rc.unslung` запускает его при загрузке системы, а скрипт автоматически перезапускает ноду через 3 секунды в случае аварийного завершения. Файлы размещаются в `/opt`, команды - в `/opt/bin`, а служебные файлы - в `/tmp/gowave-node`.

Особенности:
- Логи ноды не засоряют системный журнал роутера; читайте их через `gowave-node logs`.
- Обновление из веб-панели требует systemd, поэтому на Entware ноду следует обновлять командой `gowave-node update`.
- Обязательно откройте `NODE_PORT` и входящие порты Xray в файрволе роутера на WAN-интерфейсе.

## Переезд со старой установки remnanode

Если на сервере работала нода под старым названием (`remnanode`), установщик переводит её на службу `gowave-node` автоматически:
- Каталог установки сохраняется (например, `/opt/remnanode`), чтобы не сломались пути к сертификатам и кастомному ядру;
- Ключ, порт и параметры из `.env` сохраняются, старые имена переменных конвертируются в новые;
- Команды `remnanode` и `remnanode-go` остаются симлинками на `gowave-node`;
- Старая служба выключается только после того, как новая скачана и проверена. В случае ошибки прежняя служба и конфигурация возвращаются на место.

Если старая нода располагалась в нестандартном каталоге, укажите его в `GOWAVE_NODE_LEGACY_INSTALL_DIR`.

## Ручная установка без установщика

Бинарники `gowave-node-linux-<архитектура>` и `checksums.txt` доступны в [релизах gowave-node](https://github.com/aaaSaZaN/gowave-node/releases).

1. Положите бинарник в `/opt/gowave-node/gowave-node` и дайте права на выполнение: `chmod +x /opt/gowave-node/gowave-node`.
2. Создайте файл окружения `/opt/gowave-node/.env` по [описанию настроек](../configuration/).
3. Создайте службу systemd `/etc/systemd/system/gowave-node.service`:

```ini
[Unit]
Description=gowave-node
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/gowave-node
ExecStart=/opt/gowave-node/gowave-node
RuntimeDirectory=gowave-node
RuntimeDirectoryMode=0700
UMask=0077
Restart=always
RestartSec=3
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target
```

4. Установите ядро Xray и создайте системные симлинки:

```bash
/opt/gowave-node/gowave-node core install -y
ln -sfn /opt/gowave-node/gowave-node /usr/local/bin/gowave-node
ln -sfn /opt/gowave-node/gowave-node /usr/local/bin/xlogs
systemctl daemon-reload
systemctl enable --now gowave-node
```
