Переезд с 3x-ui в GoWave сохраняет клиентов, пароли и входящие соединения. Данные читаются прямо из SQLite-файла панели.

## Подготовка

Перед началом остановите службу 3x-ui, чтобы база не менялась во время чтения:

```bash
systemctl stop x-ui
```

Сделайте резервную копию базы данных GoWave. Импорт выполняется одной транзакцией: если возникнет ошибка, GoWave вернётся к исходному состоянию.

## Запуск импорта

Если файл базы находится по стандартному пути `/etc/x-ui/x-ui.db`, путь указывать необязательно:

```bash
# По умолчанию читает /etc/x-ui/x-ui.db
gowave import 3x-ui

# Или с явным путём к файлу
gowave import 3x-ui /etc/x-ui/x-ui.db
```

Импорт также доступен через меню `gowave rescue` (пункт 11).

## Что переносится

- Учётные данные: UUID клиентов VLESS, пароли для Trojan и Shadowsocks.
- Лимиты и сброс трафика: значения лимита в байтах, стратегии сброса (день, неделя, месяц, год или без сброса).
- Сроки действия: абсолютное время окончания. Если срок уже прошёл, клиент получает статус `EXPIRED`. Если исчерпан лимит байт - статус `LIMITED`.
- Идентификаторы: Telegram ID и комментарии клиентов.
- Токены ссылок подписки (`subId`). Если несколько клиентов делят общий токен, первому остаётся прежний, а остальным выдаются новые уникальные токены.
- Статистика трафика: входящий, исходящий, суммарный объём и отметка последнего визита онлайн.
- Входящие соединения (inbounds): для каждого создаётся профиль конфигурации GoWave и внутренний сквад вида `3x-ui-<id>-<тег>`.

## Что настроить после импорта

1. **Ноды.** Установите GoWave Node на серверы, через которые пойдёт трафик, и подключите их к панели.
2. **Хосты.** Создайте публичные хосты и привяжите их к импортированным сквадам.
3. **Ссылки подписок.** Если у клиентов изменились токены или домен панели, выдайте им обновлённые ссылки.
4. **Ограничения по устройствам.** Ограничения по IP из 3x-ui не превращаются в HWID: настройте лимиты устройств в панели GoWave заново.
5. **Клиенты с отложенной активацией.** Клиенты с отрицательным сроком действия вызывают откат импорта. Активируйте или удалите такие записи в 3x-ui перед запуском.
