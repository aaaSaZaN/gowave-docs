---
title: Требования
description: Что нужно серверу для GoWave.
sidebar:
  order: 1
---

- Linux на `amd64` или `arm64`: Debian, Ubuntu или дистрибутив семейства RHEL.
- Доступ root.
- Домен с A/AAAA-записью на IP сервера и действующий TLS-сертификат.
- Открытый порт 443/TCP; при HTTP-01 — также открытый и свободный порт 80/TCP.
- Свободный локальный порт `127.0.0.1:3000` для панели.
- Оперативная память для панели: около 50–60 МБ под нагрузкой; для PostgreSQL — ещё около 140 МБ.
- Место на диске для бинарника (около 28 МБ), веб-интерфейса, базы и резервных копий.
- Для [Docker](../docker/): Docker Engine и плагин Docker Compose; для [установки без Docker](../systemd/): systemd.
