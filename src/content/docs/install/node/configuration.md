Настройки читаются из `.env` рядом с бинарником или из `/opt/remnanode/.env`. Переменные, заданные в окружении процесса, важнее файла. Установщик сам записывает `SECRET_KEY` и `NODE_PORT`, остальное обычно трогать не нужно.

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `SECRET_KEY` | *обязательно* | Ключ из настроек ноды в панели: сертификаты и подпись для подключения |
| `NODE_PORT` | `3000` | Порт управления (TLS 1.3, mTLS и JWT RS256). Должен совпадать с портом ноды в панели |
| `XRAY_CORE_PATH` | ищется рядом или в системе | Путь к ядру Xray |
| `XRAY_LOCATION_ASSET` | папка ядра | Папка с geodata |
| `ASN_INDEX_PATH` | `/usr/local/share/asn/asn-prefixes.zip` | Индекс ASN для списков в плагинах |
| `SNI_VERIFICATION` | `false` | Требовать SNI, выданный панелью, даже при правильном mTLS |
| `NFTABLES_LOGGING` | `true` | Журналирование правил файрвола в ядре |
| `NFTABLES_ACCEPT_REPLY_TRAFFIC` | `false` | Не блокировать ответный трафик уже установленных соединений |
| `DISABLE_HASHED_SET_CHECK` | `false` | Перезапускать ядро при каждой синхронизации конфигурации |
| `REMNANODE_RUNTIME_DIR` | `/run/remnanode` | Служебная папка конфигурации и CLI |
| `XTLS_API_SOCKET_PATH` | `/run/remnanode/xray.sock` | gRPC-сокет Xray |
| `INTERNAL_REST_TOKEN` | случайный | Токен внутреннего HTTP, обычно не задаётся |
| `INTERNAL_SOCKET_PATH` | случайный | Внутренний сокет конфигурации и вебхуков |
| `S6_COMMAND_DIR`, `XRAY_S6_SERVICE_DIR` | `/command`, `/run/service/xray` | Для запуска Xray через s6, как в оригинальном контейнере |

Служебная папка должна принадлежать пользователю службы с правами `0700`. Конфигурация Xray хранится только там и в `/etc/xray/config.json` не копируется.

## Плагины

Поддерживаются фильтры входящего и исходящего трафика, списки ASN, обнаружение торрентов с отчётами в панель, разрыв соединений и вебхуки после запуска. Для фильтров нужны `nft`, `ss` и `CAP_NET_ADMIN`. Если их нет, нода сообщит панели, что применить правила не удалось.

## Своё ядро

В конфигурации ноды можно указать своё ядро Xray (`xrayConfig.geodata.core`: адрес и SHA-256) и дополнительные файлы данных (`geodata.assets`). Своё ядро сначала проверяется на текущей конфигурации и только потом включается. `remnanode core reset` возвращает стандартное.
