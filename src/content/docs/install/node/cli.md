## Команды

| Команда | Что делает |
| :--- | :--- |
| `gowave-node status` | Состояние ноды и ядра |
| `gowave-node status --wait-running` | Дождаться, пока ответит служба управления (до 30 секунд) |
| `gowave-node status --wait-ready` | Дождаться, пока нода получит конфигурацию и Xray запустится (до 2 минут) |
| `gowave-node logs -n 100 -f` | Журнал ноды |
| `gowave-node xlogs -n 100 -f` | Журнал Xray |
| `gowave-node restart` | Перезапуск |
| `gowave-node update -y` | Обновить ноду до последнего релиза |
| `gowave-node core install -y` | Поставить последнюю стабильную версию Xray |
| `gowave-node core install --version v26.7.28 -y` | Поставить конкретную версию Xray |
| `gowave-node core reset` | Вернуть стандартное ядро вместо своего |

Запускайте команды от root: CLI находит ноду через служебный файл в `/run/gowave-node`. На установках, переехавших со старого имени, работают и прежние команды `remnanode` и `remnanode-go`.

## Как обновляется нода

Нода обновляется из релизов [gowave-node](https://github.com/aaaSaZaN/gowave-node/releases), ядро - из релизов XTLS/Xray-core. Если явно указанной версии нет, команда завершается с ошибкой и не ставит другую. Каждый скачанный файл сверяется с опубликованной SHA-256 до замены.

Предыдущий бинарник сохраняется. `gowave-node update` ждёт перезапуска прямо в терминале. При обновлении из панели на systemd за перезапуском следит временная служба `systemd-run` и возвращает прежний бинарник, если нода не поднялась.

## Обновление из панели

В карточке Go-ноды нажмите на версию Xray Core: откроется выбор официального release или pre-release, а также поле для прямой HTTPS-ссылки на бинарник или архив. Версия самой ноды выбирается на вкладке **GoWave Node Go**, список берётся из релизов gowave-node.

Обновление из панели требует systemd. На Entware обновляйте ноду командой `gowave-node update`. На хосте только с s6 обновление из панели работает при внешнем супервизоре перезапуска, без него нода отклонит запрос и оставит прежний бинарник.
