Панель слушает только `127.0.0.1:3000` и наружу отдаётся через reverse proxy с HTTPS. Установщик настраивает его сам, а для ручной установки есть готовые настройки:

- [Caddy](../caddy/): проще всего, сертификат выпускается и продлевается сам.
- [Nginx](../nginx/): если Nginx уже стоит на сервере. Сертификат выпускается через Certbot.
- [Панель и нода на одном сервере](../ssl-preread/): Nginx делит порт 443 между панелью и Xray с REALITY.

Подойдёт и любой другой прокси (Angie, Traefik, HAProxy, Cloudflare Tunnel). Ему нужно:

- передавать запросы на `http://127.0.0.1:3000` с путём без изменений;
- передавать заголовки `Host`, `X-Forwarded-For` и `X-Forwarded-Proto`;
- пропускать WebSocket (см. ниже);
- принимать загрузки до 50 МБ, если вы восстанавливаете бэкапы через панель.

Если прокси работает в Docker, запустите его с `network_mode: host`: панель слушает `127.0.0.1` хоста, и из обычной сети Docker её не видно.

Если задан [путь панели](../../installer/#путь-панели) (`PANEL_BASE_PATH`), отдельно его в прокси настраивать не нужно: проксируйте весь домен как есть. Путь меняет только адрес веб-интерфейса, API и подписки остаются на `/api/...`.

:::tip[WebSocket]
Заголовки `Upgrade` и `Connection` нужны для SSH-терминала нод в панели.
:::
