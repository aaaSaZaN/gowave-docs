GoWave читает базу 3x-ui (SQLite) и переносит из неё клиентов и inbound'ы. Установщик этот импорт не предлагает, он запускается командой. Схема сверена с исходниками 3x-ui v2.8.5, на реальных базах импорт пока проверен мало, поэтому сначала попробуйте его на тестовой базе GoWave.

Перед импортом остановите 3x-ui (`x-ui stop`) и сделайте копию базы GoWave. Запускайте команду из каталога панели:

```bash
# По умолчанию /etc/x-ui/x-ui.db
gowave import 3x-ui

# Другой путь
gowave import 3x-ui /root/x-ui.db
```

В меню `gowave rescue` это пункт 11. Как запустить импорт, если панель в Docker, написано в [справочнике CLI](../../reference/cli/).

Импорт пишет в GoWave одной транзакцией. Любая ошибка откатывает всё, база GoWave остаётся как была.

## Что переносится

Каждый inbound становится профилем конфигурации с одним этим inbound'ом и отдельным внутренним сквадом `3x-ui-<id>-<tag>`. Клиенты inbound'а попадают в этот сквад как пользователи.

| В 3x-ui | В GoWave |
| :--- | :--- |
| `email` клиента | Имя пользователя. Без email - `3xui_<inbound>_<номер>` |
| UUID (VLESS), пароль (Trojan, Shadowsocks) | Те же учётные данные |
| `totalGB` | Лимит трафика. В базе 3x-ui это уже байты, несмотря на название |
| `expiryTime` | Срок действия (из миллисекунд). Без срока - бессрочно |
| `enable` клиента и inbound'а | Статус: выключенный становится `DISABLED`, истёкший - `EXPIRED`, исчерпавший лимит - `LIMITED` |
| `reset` 1, 7, 30, 365 дней | Сброс трафика раз в день, неделю, месяц, год |
| `tgId`, `comment` | Telegram ID, описание |
| `subId` | Короткий UUID подписки |
| `client_traffics` | Использованный и накопленный трафик, время последнего подключения |

## Ограничения

- Поддерживаются только VLESS, Trojan и Shadowsocks. Inbound с другим протоколом откатывает весь импорт.
- Клиент с отложенным сроком (отрицательный `expiryTime`, отсчёт с первого подключения) тоже откатывает импорт. Активируйте или переведите таких клиентов на обычный срок до импорта.
- Если один email встречается в нескольких inbound'ах с разными учётными данными, импорт откатится. Дайте таким клиентам разные email.
- Клиенты с общим `subId`: первый сохраняет его, остальные получают отдельный токен, и им нужно выдать новые ссылки. Сохранённый `subId` оставляет прежний токен, но домен и путь старой ссылки могут потребовать настройки reverse proxy.
- Лимиты по IP в лимиты HWID не превращаются. Другие периоды сброса, настройки панели, логины администраторов и внешний Nginx из x-ui-pro переносятся вручную.

Перед запуском создайте публичные хосты для профилей и подключите [GoWave Node](../../install/node/install/) к серверам, где работал Xray.
